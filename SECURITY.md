# Security

Please do not open a public issue for a security problem.

Report it privately through GitHub: **Security → Report a vulnerability** on this repository. Say what is affected
(a component, the registry, the docs site or the MCP server), how to reproduce it, and what an attacker could do.
We will reply, tell you what we decide, and tell you when a fix ships.

The docs site and the registry serve static content and read-only endpoints; the MCP server at `/mcp` is read-only and
needs no sign-in.
